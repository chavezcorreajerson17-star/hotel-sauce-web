HOTEL SAUCE - SITIO WEB COMPLETO

ARCHIVOS INCLUIDOS
- index.html: página principal.
- styles.css: diseño adaptable a celular y computadora.
- script.js: interacciones y enlace de WhatsApp.
- assets/: fotografías utilizadas en la página.
- VER-EN-CELULAR.bat: ayuda para probar la página en otro dispositivo conectado al mismo Wi-Fi.

PRUEBA EN COMPUTADORA
Abre index.html con Chrome o Edge. Mantén la carpeta assets junto a los archivos principales.

PRUEBA EN CELULAR (MISMO WI-FI)
1. En Windows, haz doble clic en VER-EN-CELULAR.bat.
2. Revisa la dirección IP que aparece en la ventana.
3. En el celular conectado al mismo Wi-Fi, abre la dirección indicada, por ejemplo: http://192.168.1.25:8080
4. Mantén abierta la ventana mientras haces la prueba.

PUBLICACIÓN
Sube todos los archivos y la carpeta assets a la raíz del repositorio de GitHub o al servicio de alojamiento estático. No subas únicamente index.html.
